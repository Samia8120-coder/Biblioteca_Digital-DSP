# Biblioteca_Digital-DSP
Trabalho Prático 1 -  Desenvolvimento de um Cofre Digital de Arquivos com FastAPI
Persistência, Serialização, Integridade, Segurança e Backup

Tema 15 — Biblioteca Digital  
O sistema deverá armazenar materiais bibliográficos digitais, como: <br>
&nbsp;&nbsp;&nbsp;&nbsp;livros; <br>
&nbsp;&nbsp;&nbsp;&nbsp;artigos; <br>
&nbsp;&nbsp;&nbsp;&nbsp;apostilas; <br>
&nbsp;&nbsp;&nbsp;&nbsp;documentos PDF; <br>
&nbsp;&nbsp;&nbsp;&nbsp;arquivos EPUB; <br>
&nbsp;&nbsp;&nbsp;&nbsp;arquivos TXT. <br>
Além dos metadados gerais, deverão existir informações como: <br>
&nbsp;&nbsp;&nbsp;&nbsp;título; <br>
&nbsp;&nbsp;&nbsp;&nbsp;autor; <br>
&nbsp;&nbsp;&nbsp;&nbsp;ano; <br>
&nbsp;&nbsp;&nbsp;&nbsp;gênero ou categoria; <br>
&nbsp;&nbsp;&nbsp;&nbsp;editora. <br>
Requisito específico <br>
O sistema deverá permitir realizar buscas combinadas utilizando: <br>
&nbsp;&nbsp;&nbsp;&nbsp;autor; <br>
&nbsp;&nbsp;&nbsp;&nbsp;ano; <br>
&nbsp;&nbsp;&nbsp;&nbsp;categoria; <br>
&nbsp;&nbsp;&nbsp;&nbsp;formato do arquivo.
